# Tornado.io

Gra w przeglądarce: jesteś małą trąbą powietrzną. Zjadasz drobne rzeczy i rośniesz, cięższe podnosisz i ciskasz
nimi w budynki, które rozpadają się tak, jak są zbudowane — szyby pękają promieniście, mur sypie się cegłami,
dachówki odlatują, a dach spada, gdy zabraknie ścian.

- Gra: `index.html` — https://michalstankiewicz4-cell.github.io/Tornado.io/
- Laboratorium zniszczeń: `labs/destruction.html`

Silnik rozpadu (DestructKit, `js/destruct/`) i budynki z części (HouseKit, `js/models/houses/`) — opis w `CLAUDE.md`.
UI, niebo, materiały, rośliny, skały i przedmioty skopiowane z GameLaboratory.
